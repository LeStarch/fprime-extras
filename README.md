# fprime-extras
A set of extra components for use with F Prime

## Contents

* `FprimeExtras/Update` — image update subtopology, including the `DeltaPatcher` component that applies uplinked
  SPatch delta files on board (see `FprimeExtras/Update/DeltaPatcher/docs/sdd.md`).
* `python/` — `fprime-extras-spatch`, the ground tool that creates, applies, verifies and inspects SPatch files
  (see `python/README.md`).
